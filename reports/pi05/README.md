## 夹爪排查（2026-09-28）

用户观察到 π0.5 靠近红块但未闭合。检查最近一轮 `20260928T060035.730478Z` 的 320 个实际动作：最后一维范围 `[-1.0, -0.99347]`，全为张开，闭合指令为 0 次；最初 300 步探针也全为张开。

代码核对：π0.5 输出的第七维直接进入 Panda 夹爪；限幅不会改变符号。上游 RLinf LIBERO 评测同样直接传递动作，没有额外反号或 0–1 映射。当前 robosuite 1.5.2 `PandaGripper.format_action` 的约定为 -1 张开、+1 闭合，通过符号累积控制开度，因此 -0.99 与 -1 都是在张开。

远程执行 `TABLETOP_GPU=0 .venv/bin/python scripts/diagnose_gripper.py`，只新建独立仿真，没有修改网页场景、权重或策略。结果见 [诊断原始记录](gripper-diagnostic.json)：

| 检查 | 结果 |

| 空中张开→闭合→再张开，连续三轮，每阶段 25 步 | 全部响应正常；两指关节位置差约 78–79 mm → 1.55 mm → 78.45 mm（该差值是开度指标，不是精确指垫间距） |
